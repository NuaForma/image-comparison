NuaForma Kotlin Image Assertions

Package dev.nuaforma.image.comparison.kotlin. Optional JVM test API, requiring Java 17. Add only dev.nuaforma:image-comparison-kotlin; core, Kotlin standard library and annotations are transitive. No release is published yet.

Each call uses a fresh Java engine. compareImages returns every result state. assertImagesMatch returns MATCH or throws ImageComparisonAssertionError for MISMATCH and SIZE_MISMATCH. A configuration exception propagates unchanged. Invalid options throw IllegalArgumentException. Neither function writes files.

ImageComparisonOptions

The constructor is internal; configure it through a function's receiver lambda, marked with the public @ImageComparisonDsl annotation.

MemberDefault and contract
pixelTolerance: Double0.1; finite [0,1). Zero compares exact ARGB; positive tolerance independently bounds normalized RGB and alpha distance.
allowedDifferentPixelsPercent: Double0.0; finite [0,100]. Inclusive percentage of non-excluded pixels exceeding tolerance; accepted results retain the measured percentage.
threshold: Int5; positive grouping distance in pixels.
excludeRectangle(minX: Int, minY: Int, maxX: Int, maxY: Int)Inclusive nonnegative ordered coordinates, entirely inside the expected image. Bounds are checked before comparison.

ImageComparisonAssertionError

Extends AssertionError; its constructor is internal. The public comparisonResult: ImageComparisonResult retains the mutable Java result and difference image for caller-controlled handling. The message contains optional context, state, dimensions, differing-pixel percentage and region count. It is locale-independent and includes no image contents.

Policies and limits

Core comparison uses RGB and alpha, including hidden RGB at alpha zero. Exclusions affect both numerator and denominator; all excluded means zero. Unequal dimensions always mean SIZE_MISMATCH and 100%, without resizing. Grouping uses a heap worklist with constant call-stack use. Rectangle fills/visual filters are not exposed. Inputs/results retain core ownership semantics and are not immutable snapshots. Rectangle collections are never null; MATCH and SIZE_MISMATCH are empty. Default lists are independent and mutable; assigning null resets to a new empty list, while non-null assignments retain caller aliasing/mutability. Owned drawing contexts are disposed without invalidating caller/result images. Concurrent input mutation is unsupported. No resource-limit or file-decoding guarantee is added.
